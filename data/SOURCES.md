# Sources

The township shipped with this repository is **entirely synthetic**. It is
generated by `civictwin/synth/township.py` from a seed, and no external data is
downloaded at any point. This file records what a real build would draw on, and
the obligations that would come with it.

| Source | Used for | Licence | Accessed |
|---|---|---|---|
| — | Everything in `data/township.json` | Generated, no licence | n/a |

## Hazard providers

civic-twin does not forecast weather; it consumes somebody else's forecast. Any
provider plugs in through an adapter (`civictwin/hazard/adapters/`), and every
forecast carries the source it came from and the provenance class of that
source, so a number on the dashboard can be traced back to the model that
produced it.

| Provider class | Example | What civic-twin takes | Licence note |
|---|---|---|---|
| Rainfall / flood ensemble | national meteorological service, ECMWF | quantiles of rainfall or depth | varies; usually attribution |
| Deterministic flood model | a single-run hydraulic model | one value, widened into a band and marked as our widening | varies |
| Satellite flood extent | Copernicus EMS, Sentinel-1 derived | observed footprint, for validation | Copernicus free licence |
| Cyclone track | regional specialised centre | track and intensity | varies |

None of these ship with the repository. The synthetic township draws its
rainfall from a fitted Gumbel distribution instead, which is stated wherever the
figure appears.

## If the real-data pipeline (spec 07) is built

| Source | Would be used for | Licence | Obligation |
|---|---|---|---|
| OpenStreetMap | Roads, bridges, hospitals, substations, water works | ODbL 1.0 | Attribution, share-alike on derived databases |
| OpenCelliD | Cell tower positions | CC BY-SA 4.0 | Attribution, share-alike |
| Copernicus DEM | Elevation, and the HAND field derived from it | Copernicus free licence | Attribution to the European Union / Copernicus |
| CARTO basemap tiles | Map background in the frontend | CARTO free tier | Attribution in the map frame |

Every asset in the model carries a `provenance` field of `observed`, `inferred`
or `synthetic`, so any figure can be traced to how much of it was invented.
In the shipped township: 15 assets observed, 29 inferred, 31 synthetic — the
"observed" marking there means *"this is the kind of asset that would come from
a source"*, not that it did.

## Runtime

No component makes a network call at runtime. All fetching would happen in the
offline pipeline; the API and the frontend read local files only. The single
exception is the basemap tile request made by the user's own browser.
