## 4. `Township` required methods

Implement exactly these. All must be O(1) or O(|links|) with caches built once
in `__post_init__`; **no repeated linear scans in hot paths**.

```python
def providers(self, asset_id: str, kinds: set[LinkKind] | None = None) -> list[str]
def dependents(self, asset_id: str, kinds: set[LinkKind] | None = None) -> list[str]
def upstream(self, asset_id: str, kinds: set[LinkKind] | None = None) -> set[str]
    """Transitive closure of providers. Cycle-safe (visited set)."""
def downstream(self, asset_id: str, kinds: set[LinkKind] | None = None) -> set[str]
def assets_of(self, portfolio: Portfolio) -> list[Asset]
def zone_providers(self, zone_id: str) -> set[str]
    """Direct providers of a zone: substation, feeder, tank, towers."""
def zone_dependency_closure(self, zone_id: str) -> set[str]
    """zone_providers ∪ upstream of each. Cached."""
def served_population(self, asset_id: str) -> int
    """Sum of population of zones whose dependency closure contains asset_id."""
def road_graph(self) -> tuple[dict[int, list[tuple[int, str, float]]], ...]
    """Adjacency: node -> [(neighbour, edge_id, travel_time_h)]. Cached."""
def validate(self) -> list[str]
    """Returns a list of problems; empty list means valid. See §6."""
def to_dict(self) -> dict
```

**Caching rule:** build `_providers_by_target`, `_dependents_by_source`,
`_closure_cache`, and `_adjacency` once in `__post_init__`. Invalidate nothing —
the `Township` is immutable after construction. Scenario changes are overlays
(spec 02), never mutations.

## 6. `Township.validate()` — required checks

Return a string per problem found. Empty list = valid.

1. Every `Link.source` and `Link.target` exists in `assets`.
2. No self-links.
3. No cycles in `POWERS`, `SUPPLIES_WATER`, `BACKHAULS`, `HOSTED_ON`
   considered together. (`CONTROLS` and `FUELS` MAY form cycles — that is the
   intended cyber feedback loop; exclude them from this check.)
4. Every asset's `node` exists in `nodes`.
5. Every `RoadEdge.u`/`v` exists in `nodes`.
6. Road graph is connected, or every island is reported.
7. Every zone has a `substation`, `feeder`, `tank`, and ≥1 tower, all existing.
8. Every zone's `population > 0` and `0 ≤ vulnerable_fraction ≤ 1`.
9. Every asset with `kind` in {TOWER, PUMP, EXCHANGE, TREATMENT, HOSPITAL}
   has ≥1 `POWERS` provider.
10. Every `TOWER` has ≥1 `BACKHAULS` provider.
11. Every `hand_m ≥ 0`, `fragility_median_m > 0`, `fragility_beta > 0`.
12. Every crew's `depot` exists and is an asset of kind `DEPOT`.
13. At least one asset of each kind in {SUBSTATION, PUMP, TANK, TOWER,
    EXCHANGE, HOSPITAL, BRIDGE, DEPOT}.

## 7. `civictwin/config.py`

Single module holding every tunable constant as a frozen dataclass. **No magic
numbers anywhere else in the codebase.**

```python
@dataclass(frozen=True, slots=True)
class LossWeights:
    energy: float = 1.0
    water: float = 1.0
    comms: float = 0.5
    health: float = 3.0
    mobility: float = 0.5

@dataclass(frozen=True, slots=True)
class HazardConfig:
    rain_threshold_mm: float = 60.0
    rain_scale_mm: float = 90.0        # W = (rain - threshold) / scale
    field_bumps: int = 3               # Gaussian bumps in the spatial field
    field_sigma_frac: float = 0.35     # bump width as fraction of extent
    field_amplitude: float = 0.45      # ± variation around 1.0
    recession_base_h: float = 12.0
    recession_per_w_h: float = 12.0    # duration = base + per_w * W
    rise_hours: float = 6.0            # linear rise to peak
    gumbel_loc_mm: float = 85.0
    gumbel_scale_mm: float = 38.0
    pluvial_drain_capacity_mm_h: float = 18.0
    pluvial_pond_factor: float = 0.04  # m of ponding per mm/h of excess

@dataclass(frozen=True, slots=True)
class RoadConfig:
    impassable_depth_m: float = 0.30
    speed_reduction_per_m: float = 2.5  # kph lost per cm... see spec 02 §5.4

@dataclass(frozen=True, slots=True)
class DamageConfig:
    # multipliers on fragility_median_m giving the median for each state
    state_multipliers: tuple[float, ...] = (0.6, 1.0, 1.5, 2.2)
    #   -> SLIGHT, MODERATE, EXTENSIVE, COMPLETE
    residual_functionality: tuple[float, ...] = (1.0, 0.9, 0.5, 0.1, 0.0)
    #   -> NONE, SLIGHT, MODERATE, EXTENSIVE, COMPLETE
    repair_multipliers: tuple[float, ...] = (0.0, 0.25, 1.0, 2.5, 5.0)

@dataclass(frozen=True, slots=True)
class EnergyConfig:
    deenergise_flood_fraction: float = 0.25  # feeder switched off above this
    transfer_capacity_margin: float = 0.15   # spare capacity needed to accept load

@dataclass(frozen=True, slots=True)
class CommsConfig:
    handover_capacity_factor: float = 1.4    # neighbour can absorb 40% extra
    demand_surge_factor: float = 2.5
    battery_load_exponent: float = 1.0       # drain ∝ load^exponent

@dataclass(frozen=True, slots=True)
class ResponseConfig:
    site_dry_depth_m: float = 0.10
    crew_travel_speed_kph: float = 25.0
    fuel_truck_speed_kph: float = 20.0
    refuel_adds_hours: float = 48.0
    manual_operation_penalty_h: float = 4.0  # SCADA lost -> crew must attend

@dataclass(frozen=True, slots=True)
class SimConfig:
    horizon_h: float = 72.0
    dt_h: float = 1.0
    health_access_minutes: float = 15.0
    mobility_access_minutes: float = 25.0

@dataclass(frozen=True, slots=True)
class RiskConfig:
    alpha: float = 0.95              # CVaR level
    n_scenarios_train: int = 1000
    n_scenarios_test: int = 500
    seed_train: int = 1
    seed_test: int = 202

@dataclass(frozen=True, slots=True)
class Config:
    loss: LossWeights = LossWeights()
    hazard: HazardConfig = HazardConfig()
    road: RoadConfig = RoadConfig()
    damage: DamageConfig = DamageConfig()
    energy: EnergyConfig = EnergyConfig()
    comms: CommsConfig = CommsConfig()
    response: ResponseConfig = ResponseConfig()
    sim: SimConfig = SimConfig()
    risk: RiskConfig = RiskConfig()

DEFAULT = Config()
```

`Config` must round-trip to/from JSON so an ensemble member can serialise its
perturbed config (spec 03 §8).

## 8. Synthetic township generator — `civictwin/synth/township.py`

```python
def generate(seed: int = 42, scale: float = 1.0) -> Township
```

Deterministic from `seed`. Default output must satisfy `validate() == []` and
produce the asset counts below. `scale` multiplies the grid dimensions.

### 8.1 Geography

- Extent: 6000 m × 6000 m. Origin at (0, 0), CRS EPSG:32644, origin lon/lat
  `(80.20, 13.05)` (for map display only).
- **River:** a polyline from `(0, 2600)` to `(6000, 3400)` with three control
  points jittered by ±250 m. Width 120 m.
- **Elevation / HAND:** `hand_m(x, y) = clip(distance_to_river_m / 260, 0, 14)`
  plus a smooth ridge on the west side: `+3.0 * exp(-((x-1200)²+(y-4200)²)/2/900²)`.
  Add deterministic noise of ±0.4 m from the seeded generator.
- **Road grid:** 13 × 13 nodes at 500 m spacing (169 nodes). Edges between
  orthogonal neighbours → 312 edges. Delete 18 edges deterministically to break
  perfect regularity (choose by the seeded RNG, then re-check connectivity and
  restore any edge whose deletion disconnects the graph).
- **Bridges:** only 2 road edges cross the river; all other river-crossing edges
  are deleted. Bridges at approximately `x = 1750` and `x = 4250`.
  Each bridge is an `Asset(kind=BRIDGE)` and the corresponding `RoadEdge` has
  `host_asset` set to it.
- **Underpasses:** 3 road edges with `hand_m` forced to `0.2` and a
  `Asset(kind=UNDERPASS)` host.

### 8.3 Deliberate structural traps (these drive the demo — implement exactly)

1. **Shared-substation fake redundancy.** Zones Z9–Z12 are covered by towers
   T5 and T6. Both T5 and T6 are powered by **S2** (the low-lying east
   substation). The UI must be able to discover this via `upstream()`.
2. **Co-location trap.** The primary fibre `FIBRE_1` (X1→X2) and the backup
   `FIBRE_2` are both `HOSTED_ON` bridge `B1`. Losing B1 severs east backhaul
   entirely.
3. **Cross-portfolio hospital trap.** H2 sits on high ground (`hand≈5`, rarely
   floods) but its water comes from tank K3, refilled only by pump **P2**
   (`hand≈0.9`), which is powered by **S2**. So H2 fails from a flood that never
   touches it.
4. **Recovery trap.** All three depots are on the **west** bank. Repairing any
   east-bank asset requires crossing B1 or B2. If both bridges are impassable,
   east-bank recovery stalls.
5. **SCADA loop.** P2 and P3 have `scada_controlled=True` and a `CONTROLS` link
   from X2. Losing X2 means P2/P3 need a crew on site before they can restart,
   adding `manual_operation_penalty_h`.
6. **Stormwater feedback.** The two `STORMWATER_PUMP` assets are powered by S2.
   If S2 is down, pluvial drainage capacity in the east basins drops by 60%,
   deepening the flood there. (Implement in spec 02 §4.4.)

`vulnerable_fraction ∈ [0.06, 0.22]`. Zones 9–12 are the east-bank low zones.

## 10. Acceptance tests — `tests/test_ontology.py`

Each bullet is one test function.

1. `test_generate_deterministic`: `generate(42)` twice → identical `to_dict()`.
2. `test_generate_valid`: `generate(42).validate() == []`.
3. `test_asset_counts`: counts match §8.2 exactly.
4. `test_zone_count_and_population`: 16 zones, total population in [70k, 90k].
5. `test_upstream_cycle_safe`: add an artificial `CONTROLS` cycle; `upstream()`

6. `test_trap_shared_substation`: `upstream("T5") & upstream("T6")` contains
   `"S2"`.
7. `test_trap_fibre_colocation`: both fibre assets have `B1` as a `HOSTED_ON`
   provider.
8. `test_trap_hospital_water`: `"S2" in township.upstream("H2")` via the
   P2 → K3 → H2 chain.
9. `test_trap_depots_west`: every depot's `x < 3000` and reaching any east-bank
   asset from any depot requires a bridge edge.
10. `test_served_population_monotone`: `served_population("S2")` >
    `served_population("T5")`.
11. `test_roundtrip_json`: `load_township(save_township(t))` equals `t`.
12. `test_road_graph_connected`: the road graph has one component.
13. `test_no_river_crossing_except_bridges`: exactly 2 edges have
    `host_asset` of kind `BRIDGE`.
14. `test_config_roundtrip`: `Config` → JSON → `Config` is equal.
15. `test_validate_catches_dangling_link`: injecting a link to a missing asset
    produces exactly one validation error.

**Performance test:** `generate(42)` completes in under 2 seconds;
`township.upstream()` over all assets completes in under 50 ms.
